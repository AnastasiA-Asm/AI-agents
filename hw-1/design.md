# Данные и расчёты

## Поставка

Один файл tracker-v2.html содержит разметку, стили и JavaScript. Обязательная версия хранит состояние в памяти на время работы страницы.

## Модель задачи

| Поле | Тип | Смысл и ограничения |
|---|---|---|
| id | строка | Уникальный идентификатор задачи |
| title | строка | Название после trim, непустое |
| hours | число | Конечное число от 0,5 до 24, кратное 0,5 |
| done | логическое значение | Выполнена ли задача |

Основное состояние — список всех задач. Фильтр и значения формы хранятся отдельно от него.

Введённые значения формы сохраняются как текст до успешной проверки: это позволяет оставить пустое или ошибочное значение в поле и показать ошибку рядом с ним.

## Изменение состояния

- Добавление: проверить оба поля, затем создать задачу с уникальным id и done=false.
- Удаление: удалить задачу по id из общего списка.
- Переключение: изменить done выбранной задачи по id.
- После изменения данных: обновить показатели и видимый список с учётом текущего фильтра.

Если форма содержит ошибку, список задач не меняется, введённые значения остаются в полях.

## Проверка ввода

Название:
1. Удалить пробелы по краям.
2. Отклонить пустой результат.
3. При добавлении сохранить очищенное название.

Часы:
1. Проверить, что значение после удаления пробелов по краям непустое.
2. Преобразовать значение в число.
3. Проверить, что число конечное.
4. Проверить диапазон от 0,5 до 24 включительно.
5. Проверить шаг: удвоенное число часов должно быть целым.

Пустота проверяется до преобразования в число, чтобы пустой ввод не принимался за ноль.

## Расчёты

Обозначения:
- T — сумма hours всех задач;
- D — сумма hours задач с done=true;
- P — процент выполнения.

Если T = 0, то P = 0.
Иначе P = округление до ближайшего целого числа значения 100 × D / T.

Для стартового примера:
- T = 2 + 4 + 2 = 8 ч;
- D = 2 ч;
- P = 25%.

После выполнения «Практики»:
- T = 8 ч;
- D = 2 + 4 = 6 ч;
- P = 75%.

После удаления всех задач:
- T = 0 ч;
- D = 0 ч;
- P = 0%, деление не выполняется.

## Фильтрация

| Режим | Видимые задачи |
|---|---|
| Все | Все задачи |
| Активные | Задачи с done=false |
| Готовые | Задачи с done=true |

Фильтрация формирует только отображаемый список. Расчёты всегда используют полный список задач.

## Интерфейс

Форма содержит подписанные поля названия и часов, кнопку добавления и области ошибок рядом с полями.

Список позволяет переключить выполнение и удалить конкретную задачу. Показатели отображают итоговые часы, выполненные часы и процент выполнения.

На ширине 390 px элементы переносятся или располагаются вертикально. Длинные названия переносятся внутри доступной ширины.

## Необязательное localStorage

Если улучшение выбрано:
- при отсутствии сохранённых данных используется стартовый пример;
- сохранённый список, в том числе пустой, восстанавливается вместо примера;
- изменения задач сохраняются после добавления, удаления и переключения done;
- ошибки чтения или записи не прерывают работу приложения;
- при недоступности сохранения показывается сообщение, например:
  «Сохранение недоступно. Изменения останутся только в памяти до закрытия или перезагрузки страницы».

При открытии через file:// поведение localStorage зависит от браузера. Сохранение между открытиями в таком режиме не гарантируется; обязательные функции продолжают работать в памяти.
