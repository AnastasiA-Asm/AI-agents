# Изменение: мини-трекер учебных задач на неделю

## Цель

Создать автономный мини-трекер, в котором можно добавлять учебные задачи, задавать оценку в часах, отмечать выполнение и видеть общий прогресс за неделю.

## Границы

Результат реализации — один файл tracker-v2.html со встроенными CSS и JavaScript. Приложение работает в обычном браузере без установки, CDN, внешних библиотек, внешних ресурсов и API-ключей.

В обязательную часть входят:
- данные задачи: id, title, hours, done;
- стартовый пример из трёх задач;
- добавление, удаление и переключение выполнения;
- проверка названия и часов с ошибками рядом с полями;
- фильтрация видимого списка;
- общие и выполненные часы, процент выполнения;
- читаемый интерфейс на ширине 390 px без горизонтального скролла;
- подписанные поля и кнопки.

Сохранение в localStorage — необязательное улучшение. Оно не входит в базовую приёмку.

## Стартовый пример

| Задача | Часы | done |
|---|---:|---|
| Чтение | 2 | true |
| Практика | 4 | false |
| Повторение | 2 | false |

Ожидаемые показатели: всего 8 ч, выполнено 2 ч, прогресс 25%.

## Вне границ

Не добавляются календарь, выбор дат, автоматическая смена недели, аккаунты, сервер, синхронизация и другие функции, отсутствующие в постановке.

## Результат текущего этапа

Только спецификация, описание данных и расчётов, список будущих работ и проверок. Реализация выполняется отдельным запросом.
